# 💰 Personal Finance Website

A responsive **Personal Finance Management Website** built using **HTML, CSS, and JavaScript**. The project helps users understand and manage their personal finances through features such as expense tracking, budget monitoring, financial summaries, and dashboard-based visualization.

This project was developed as a **frontend group project** to apply core web development concepts in a practical application.

---

## 🚀 Features

* 📊 Personal finance dashboard
* 💰 Income and expense tracking
* 🎯 Budget management
* 📈 Financial summary
* 🗂️ Expense categorization
* 💳 Transaction management
* 📱 Responsive user interface
* 🧭 Easy navigation between pages
* ⚡ Dynamic content using JavaScript
* 🇮🇳 Indian Rupee (`₹`) currency formatting

## 📄 Main Pages

### 🏠 Dashboard

Provides an overview of the user's financial information, including income, expenses, balance, budgets, and other important financial details.

### 💸 Transactions

Displays income and expense transactions and helps users understand where their money is being spent.

### 🎯 Budget

Allows users to view budget limits for different categories and compare the allocated budget with actual spending.

Example categories include:

* Food
* Transport
* Bills
* Entertainment
* Shopping
* Other expenses

### 📊 Financial Overview

Provides summarized financial information so users can quickly understand their current financial position.

Example currency formatting function:

```javascript
function money(value) {
  return `₹ ${value.toLocaleString("en-IN")}`;
}
```

This converts numbers into the Indian number format.

Example:

```text
5000 → ₹ 5,000
100000 → ₹ 1,00,000
```
